# guit

A lightweight, low-resource desktop Git client.
一个轻量、低占用的桌面 Git 客户端。

- **[English](README-en.md)**
- **[中文](README-zh.md)**

guit covers the everyday Git workflow in one compact window, and deliberately
shows no file contents and no diffs — those open in the tools you already
configured.

guit 在一个紧凑的窗口里覆盖日常 Git 工作流，并且有意不显示文件内容和 diff——
它们会在你已经配置好的工具里打开。
